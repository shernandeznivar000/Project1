# My To-Do List

## About the Project

My To-Do List is a simple website that helps users organize their daily tasks. The user can type a task and add it to the list. Each task can be marked as completed or deleted when it is no longer needed.

## How to Use It

1. Open the website.
2. Type a task in the text box.
3. Click the "Add Task" button or press Enter.
4. Check the box when the task is completed.
5. Click "Delete" to remove a task.
6. Click "Clear Completed" to remove all completed tasks.

## What Is Needed

The project only needs a modern web browser such as Google Chrome, Microsoft Edge, Firefox, or Safari. No extra programs or libraries are required.
